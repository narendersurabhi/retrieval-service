# Plan 001: Service skeleton

Implements [spec.md](spec.md). Generated by the agent-platform service template.

## Architecture

```
src/<package>/
  domain/errors.py                 DomainError + one subclass per envelope type
  application/ports.py             Clock (the example port)
  application/health.py            CheckHealth use case
  application/telemetry.py         OpenTelemetry API helpers (no SDK)
  adapters/inbound/http/app.py     FastAPI routes, error envelope, FastAPI instrumentation
  adapters/outbound/system_clock.py  Clock adapter
  infrastructure/settings.py       ServiceSettings (<PREFIX>* env)
  infrastructure/telemetry.py      SDK providers, exporters, JSON console logs, shutdown
  bootstrap.py                     composition root: settings -> adapters -> use cases -> app
```

## Key decisions
- Health goes through a use case and a `Clock` port, so the pattern every feature follows
  is visible from the first commit.
- The error envelope is built in the inbound adapter from domain errors; transports other
  than HTTP map the same `type` values their own way.
- Telemetry helpers that need only the OpenTelemetry API live in `application/telemetry.py`
  so use cases can create spans and metrics without touching the SDK.
